About MIDI Adapter

MIDI Adapter v2.1 - Universal device-based MIDI routing adapter for MilkV Duo S (512MB).

Features:

  • USB MIDI input support (auto-discovered)
  • Bidirectional DIN MIDI via UART (configurable baudrate)
  • Network MIDI (RTP-MIDI) with separate input/output modes
  • GPIO button support with configurable triggers and debouncing
  • OSC MIDI bridge (experimental)
  • Multiple routing profiles
  • Real-time MIDI debugging
  • Web-based configuration interface (this page)
Documentation:
See /root/midi-adapter/README.md for comprehensive setup guide and hardware schematics.
